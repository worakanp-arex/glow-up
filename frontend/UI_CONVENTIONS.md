# รูปแบบส่วนหัวและการย้อนกลับ

ทุกหน้าใช้ `src/components/common/PageHeader.jsx` เพื่อกำหนดไอคอน หัวข้อ คำอธิบาย และปุ่มของหน้าในที่เดียว

- มี `h1` เพียงหนึ่งรายการต่อหน้า ชื่อในแผงย่อยใช้ `h2` แทน
- หัวข้อทั่วไปมีไอคอน 22px และตัวอักษร 24px; มือถือใช้ไอคอน 20px และตัวอักษร 19.2px
- ไอคอนใช้สีพื้นและขนาดกรอบเดียวกัน และซ่อนจากโปรแกรมอ่านหน้าจอเพราะมีข้อความหัวข้อกำกับอยู่แล้ว
- คำอธิบายอยู่ใน `description` ปุ่มดำเนินการอยู่ใน `actions`; บนมือถือปุ่มย้ายลงแถวถัดไปได้
- หน้าผู้ใช้หลัก (แดชบอร์ด บันทึกอารมณ์ เกม บทเรียน คำปรึกษา โปรไฟล์) ส่ง `eyebrow` เพื่อแสดงป้ายตัวพิมพ์ใหญ่เหนือหัวข้อ ไอคอนจะย่อลงไปอยู่ในแถวป้ายนั้น
- การ์ด แท็บ ปุ่ม และสวิตช์แบบใหม่ใช้คลาสร่วมใน `src/styles/redesign.css` (`ui-card`, `ui-tabs`, `ui-btn`, `ui-switch`) ภาพประกอบใช้ `<ImageSlot>` ดูรายชื่อไฟล์ที่รอใส่ใน `public/images/README.md`
- หน้าต้อนรับและเกี่ยวกับเราใช้ `variant="hero"` เพื่อคงหัวข้อประชาสัมพันธ์ แต่ใช้โครงสร้างและไอคอนร่วมกัน

## ปุ่มย้อนกลับ

หน้ารายการหลักและแดชบอร์ดใช้เมนูหลัก จึงไม่มีปุ่มย้อนกลับที่พาผู้ใช้ไปยังหน้าที่ไม่แน่นอน
หน้ารายละเอียด หน้าแบบฟอร์มย่อย และกิจกรรมที่เปิดจากแดชบอร์ดแสดงปุ่ม “ย้อนกลับ” เหนือหัวข้อในตำแหน่งเดียวกัน

| หน้า | ปลายทาง |
| --- | --- |
| รายละเอียดงาน | ค้นหางาน; หากเปิดจากใบสมัคร ใช้ `?from=my-applications` เพื่อกลับไปใบสมัครแม้รีเฟรชหน้า |
| สร้างประกาศงาน / รายชื่อผู้สมัคร | ประกาศงานของฉัน |
| รายละเอียดผู้สมัคร | รายชื่อผู้สมัครในงานนั้น; หากยังไม่มีข้อมูล กลับไปประกาศงานของฉัน |
| รายละเอียดคอร์ส | คอร์สเรียน |
| บทเรียน / สถานการณ์จำลอง | บทเรียนทั้งหมด |
| รายละเอียดโพสต์ / โพสต์ของฉัน / โพสต์ที่บันทึก / บุคลากร | ชุมชน |
| ความก้าวหน้า / แบบประเมินรายสัปดาห์ | แดชบอร์ด |
| โปรไฟล์ของฉัน | หน้าที่เข้ามาก่อนหน้า (ถ้าไม่ทราบ กลับหน้าหลักของบทบาท) |
| ประกาศงาน (นายจ้าง) | ประกาศงานของฉัน |
| รายละเอียดผู้สมัคร (นายจ้าง) | หน้าที่เข้ามา; หากไม่ทราบ กลับรายชื่อผู้สมัครของงานนั้น |
| รายละเอียดผู้ใช้งาน (แอดมิน) | จัดการผู้ใช้งาน |
| รายละเอียดคำปรึกษา | รายการคำปรึกษาตามบทบาทผู้ใช้ |
| ข้อมูลผู้รับคำปรึกษา | คำขอรับคำปรึกษา |
| ประวัติอารมณ์สำหรับผู้ดูแลระบบ | จัดการผู้ใช้งาน |
| ลืมรหัสผ่าน / ตั้งรหัสผ่านใหม่ | เข้าสู่ระบบ |
| ยืนยัน OTP | กลับขั้นตอนกรอกข้อมูล โดยคงค่าที่กรอกไว้ |

ใช้ `backTo` สำหรับเส้นทางที่แน่นอน และ `backLabel` เพื่ออธิบายปลายทางให้โปรแกรมอ่านหน้าจอ
ใช้ `onBack` เฉพาะการย้อนขั้นตอนภายในแบบฟอร์ม ไม่ใช้ `navigate(-1)` สำหรับหน้ารายละเอียด
หน้ารายละเอียดยังคงแสดงหัวข้อและปุ่มย้อนกลับขณะโหลด เมื่อไม่พบข้อมูล หรือเมื่อไม่มีสิทธิ์เข้าถึง

การทดสอบใน `tests/ui.spec.js` ตรวจหัวข้อหลัก ไอคอน เส้นทางย้อนกลับ และการแสดงผลทั้งเดสก์ท็อป มือถือ และโหมดมืด

ที่ความกว้างไม่เกิน 860px การ์ดงานและโพสต์ชุมชนเปิดหน้ารายละเอียดเต็ม ไม่แสดงแผงรายละเอียดใต้รายการ แบบฟอร์มคำปรึกษาอยู่ก่อนประวัติเสมอ (จอกว้างอยู่ด้านซ้าย จอแคบอยู่ด้านบน) และแบบฟอร์มบันทึกอารมณ์อยู่ก่อนประวัติบนมือถือ

คะแนนสะสมใช้ยอดจาก `/missions/me/summary` ซึ่งรวมภารกิจที่สำเร็จทั้งหมด และภารกิจประจำวันที่บันทึกผ่าน `/activity-missions/:id/log` (งานบ้าน/ออกกำลังกาย/การเรียนรู้) ส่วนแต้มทักษะงานคิด 1 ทักษะที่ตรง = 1 แต้ม และแสดงแยกจากคะแนนภารกิจ ปฏิทินเช็คอินใช้วันที่กรุงเทพฯ และจำกัดการดูย้อนหลัง 84 วัน ภารกิจประจำวันบันทึกได้วันละ 1 ครั้งต่อภารกิจ (นับตามวันที่กรุงเทพฯ)

การแจ้งเตือนใช้ลิงก์ไปยังข้อมูลที่เกี่ยวข้องตามบทบาท ข่าวใช้ `/#news-<articleId>` ล้างรายการแจ้งเตือนต้องแสดงป๊อปอัปยืนยันและไม่ลบประวัติสนทนา ทดสอบพฤติกรรมเหล่านี้ใน `tests/refinements.spec.js`

## เมนูด้านข้าง (ผู้ดูแลระบบและบุคลากรทางการแพทย์)

ผู้ดูแลระบบและบุคลากรทางการแพทย์มีเมนูจำนวนมาก จึงใช้เมนูด้านซ้าย (`components/layout/Sidebar.jsx`, คลาส `.side-nav`) พื้นขาวตัวอักษรดำ
ตามสี `--color-surface` / `--color-text` เพื่อให้โหมดมืดยังอ่านออก รายการเมนูและกลุ่มกำหนดใน `components/layout/navLinks.js` (`group`, `icon`)
บทบาทอื่นยังใช้แถบเมนูสีฟ้าด้านบน (`SecondaryNav`) บนมือถือใช้ลิ้นชักเมนูเดียวกัน ห้ามใช้ชื่อคลาส `.workspace-sidebar`

## ส่วนประกอบกลางที่ใช้ร่วมกัน

- `StatTile` ส่ง `to` หรือ `onClick` เพื่อให้การ์ดสถิติกดดูรายละเอียดได้ ทุกตัวเลขบนแดชบอร์ดควรพาไปหน้ารายการที่อธิบายตัวเลขนั้น
- `.ui-choice` (ใน `styles/redesign.css`) คือการ์ดเลือกแบบมีเครื่องหมายถูกอยู่ในการ์ด ใช้แทน checkbox ธรรมดา
- `useReasonDialog` ขอเหตุผลเป็นข้อความก่อนปฏิเสธหรือระงับ เหตุผลจะถูกส่งให้เจ้าของเรื่องในการแจ้งเตือน
- `EditorDialog` กล่องสร้าง/แก้ไขรายการเดียว (ใช้กับภารกิจ เหรียญตรา หมวดหมู่ ฯลฯ) ส่วน `IconPicker` แสดงไอคอนจริงให้เลือก ไม่ให้พิมพ์ชื่อไอคอน
- `Avatar` เลือกเองว่าจะแสดงรูป ตัวอักษรสี หรือรูปตามบทบาท `CoverPicker` เลือกภาพพื้นหลังจากภาพตัวอย่าง
- ชุดรูปโปรไฟล์/พื้นหลังที่เลือกได้อยู่ใน `constants/profileArt.js` (มีฝั่ง backend คู่กัน) เซิร์ฟเวอร์รับเฉพาะ key ไม่รับ URL ใด ๆ
- ปุ่มย้อนกลับของโปรไฟล์และหน้านายจ้างบางหน้ากลับไปหน้าที่เข้ามา (`utils/routeHistory.js`) และใช้หน้าหลักของบทบาทเมื่อไม่ทราบที่มา
- ช่วงเวลาเปิด/หมดอายุของคอร์สและภารกิจเก็บเป็นวันตามเวลากรุงเทพฯ (`utils/courseDates.js`)

## การรายงานโพสต์

ผู้ใช้รายงานโพสต์โดยเลือกหัวข้อ (และใส่รายละเอียดเพิ่มได้) โพสต์ที่ถูกรายงานจะถูกซ่อนจากผู้ใช้ทั่วไปทันทีและแจ้งเตือนแอดมิน/บุคลากร
เมื่อตรวจสอบแล้ว (คืนโพสต์ แก้ไข หรือลบ) ผู้รายงานทุกคนจะได้รับแจ้งผล ตัวอย่างหัวข้ออยู่ใน `constants/reportReasons.js`
