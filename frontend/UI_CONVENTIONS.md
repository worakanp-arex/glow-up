# รูปแบบส่วนหัวและการย้อนกลับ

ทุกหน้าใช้ `src/components/common/PageHeader.jsx` เพื่อกำหนดไอคอน หัวข้อ คำอธิบาย และปุ่มของหน้าในที่เดียว

- มี `h1` เพียงหนึ่งรายการต่อหน้า ชื่อในแผงย่อยใช้ `h2` แทน
- หัวข้อทั่วไปมีไอคอน 22px และตัวอักษร 24px; มือถือใช้ไอคอน 20px และตัวอักษร 19.2px
- ไอคอนใช้สีพื้นและขนาดกรอบเดียวกัน และซ่อนจากโปรแกรมอ่านหน้าจอเพราะมีข้อความหัวข้อกำกับอยู่แล้ว
- คำอธิบายอยู่ใน `description` ปุ่มดำเนินการอยู่ใน `actions`; บนมือถือปุ่มย้ายลงแถวถัดไปได้
- หน้าต้อนรับและเกี่ยวกับเราใช้ `variant="hero"` เพื่อคงหัวข้อประชาสัมพันธ์ แต่ใช้โครงสร้างและไอคอนร่วมกัน

## ปุ่มย้อนกลับ

หน้ารายการหลักและแดชบอร์ดใช้เมนูหลัก จึงไม่มีปุ่มย้อนกลับที่พาผู้ใช้ไปยังหน้าที่ไม่แน่นอน
หน้ารายละเอียด หน้าแบบฟอร์มย่อย และกิจกรรมที่เปิดจากแดชบอร์ดแสดงปุ่ม “ย้อนกลับ” เหนือหัวข้อในตำแหน่งเดียวกัน

| หน้า | ปลายทาง |
| --- | --- |
| รายละเอียดงาน | ค้นหางาน |
| สร้างประกาศงาน / รายชื่อผู้สมัคร | ประกาศงานของฉัน |
| รายละเอียดผู้สมัคร | รายชื่อผู้สมัครในงานนั้น; หากยังไม่มีข้อมูล กลับไปประกาศงานของฉัน |
| รายละเอียดคอร์ส | คอร์สเรียน |
| บทเรียน / สถานการณ์จำลอง | บทเรียนทั้งหมด |
| รายละเอียดโพสต์ / โพสต์ของฉัน / โพสต์ที่บันทึก / บุคลากร | ชุมชน |
| ความก้าวหน้า / แบบประเมินรายสัปดาห์ | แดชบอร์ด |
| รายละเอียดคำปรึกษา | รายการคำปรึกษาตามบทบาทผู้ใช้ |
| ข้อมูลผู้รับคำปรึกษา | คำขอรับคำปรึกษา |
| ประวัติอารมณ์สำหรับผู้ดูแลระบบ | จัดการผู้ใช้งาน |
| ลืมรหัสผ่าน / ตั้งรหัสผ่านใหม่ | เข้าสู่ระบบ |
| ยืนยัน OTP | กลับขั้นตอนกรอกข้อมูล โดยคงค่าที่กรอกไว้ |

ใช้ `backTo` สำหรับเส้นทางที่แน่นอน และ `backLabel` เพื่ออธิบายปลายทางให้โปรแกรมอ่านหน้าจอ
ใช้ `onBack` เฉพาะการย้อนขั้นตอนภายในแบบฟอร์ม ไม่ใช้ `navigate(-1)` สำหรับหน้ารายละเอียด
หน้ารายละเอียดยังคงแสดงหัวข้อและปุ่มย้อนกลับขณะโหลด เมื่อไม่พบข้อมูล หรือเมื่อไม่มีสิทธิ์เข้าถึง

การทดสอบใน `tests/ui.spec.js` ตรวจหัวข้อหลัก ไอคอน เส้นทางย้อนกลับ และการแสดงผลทั้งเดสก์ท็อป มือถือ และโหมดมืด
